# dsh-page-struct-catalog

DSH Community Market catalog source for [`dsh-page-struct`](https://www.npmjs.com/package/dsh-page-struct).

## Add to DSH

Market → Sources → add this manifest URL:

```text
https://lishuangxi1412.github.io/dsh-page-struct-catalog/source.json
```

Then Market → Discover → search **Page Structure** → Install.

## Files

- `source.json` — catalog source manifest
- `v1/plugins.json` — catalog page

The package is published on npm as `dsh-page-struct`.
